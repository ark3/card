# A question from the owner

The `card` tool stopped its run at your work on the card, and the owner, deciding what to do about the stop, has had the tool resume this session to put a question to you.
The run stays stopped while you respond, and nothing of it goes on until the owner decides.

## The question

The owner's question is between the tags below.

<question>
{{QUESTION}}
</question>

## Your response

Respond to the question for the owner, from what you know of your work in this session and from what you can read in the worktree, the card and any file your work names.
The tool prints your final response to the owner as it stands, so write it as plain prose for the owner and not as a report: give no JSON object and no outcome, because the tool reads no report from this turn.

Do not continue your work in this turn: change no file, commit nothing, and create, switch or delete no branch.
The work stays as it is because the owner has not yet decided what happens to it, and the owner's decision reaches you, if it does, in a later prompt with which the tool resumes this session to finish the work.
